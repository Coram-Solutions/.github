## Quem somos

A **Coram Solutions** é uma software house de Belém (PA). A gente constrói sistemas web e mobile, APIs, integrações e automação para empresas que precisam de software que funcione de verdade — e continue funcionando depois da entrega.

Já operamos produção em fintech, energia e educação. Por isso a conversa começa pelo seu processo, não pela tecnologia.

## O que fazemos

| | |

| **APIs e integrações** | ERP, bancos, gateways de pagamento, WhatsApp. Os sistemas que você já tem conversando entre si. |

## Como trabalhamos

1. **Conversa de 30 min.** Você conta o problema no WhatsApp ou numa call. A gente ouve antes de propor.
2. **Proposta com prazo e preço.** Escopo claro, opções quando fizer sentido, sem letra miúda.
3. **Entregas semanais.** Você vê o sistema crescer toda semana, testa e ajusta no caminho.
4. **No ar, com suporte.** Deploy, monitoramento e um canal direto para quando precisar.
